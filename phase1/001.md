# 제품 컨텍스트: 택스봇

> 출처: 소개.txt (3줄). 소개에 없는 항목은 추측하지 않고 "미정"으로 표시했다.
> 작성일: 2026-11-13

## 1. 제품 개요
- **제품명:** 택스봇
- **한 줄 설명:** 카드 내역을 연동하면 클릭 한 번으로 부가세 신고용 엑셀을 만들어 주는 서비스
- **카테고리:** 세무 / 부가세 신고 보조 (셀프 신고 도구)

## 2. 타깃 고객 (ICP)
- **핵심 타깃:** 1인 프리랜서
- **상황:** 세무사에게 맡기기에는 비용이 아깝고, 직접 하자니 번거로운 사람
- **세부 속성 (업종, 매출 규모, 과세 유형 등):** 미정

## 3. 해결하는 문제
- 세무사 비용 부담: 소규모 사업자에게는 기장·신고 대행료가 아깝다.
- 직접 신고의 귀찮음: 카드 내역을 하나씩 정리해 신고 자료를 만드는 일이 번거롭다.
- 현재 대안: 세무사 대행, 직접 수작업 정리 (경쟁 서비스는 미정)

## 4. 핵심 기능
| 기능 | 설명 |
|---|---|
| 카드 내역 연동 | 사용자의 카드 사용 내역을 서비스에 연결 |
| 원클릭 엑셀 생성 | 클릭 한 번으로 부가세 신고용 엑셀 파일 출력 |

## 5. 가치 제안 (소개 내용에서 도출)
- 세무사 없이도 부가세 신고 자료를 준비할 수 있다.
- 수작업 정리 없이 클릭 한 번으로 끝난다.
- 주의: 자동 신고(홈택스 직접 제출)까지 한다는 언급은 없다. 산출물은 "신고용 엑셀"이므로, 카피에서 "자동 신고"로 과장하지 않는다.

## 6. 포지셔닝 초안
세무사를 쓰기엔 아깝고 직접 하긴 귀찮은 1인 프리랜서를 위한, 카드 연동 기반의 원클릭 부가세 신고 자료 생성 서비스.

## 7. 미정 항목 (확인 필요)
- 가격 및 과금 방식
- 경쟁사 / 대체재 비교
- 지원 카드사, 지원 업종, 지원 과세 유형 (일반/간이)
- 홈택스 연계 여부, 신고 결과에 대한 책임 범위
- 보안·개인정보 처리 (카드 내역 연동 관련)
- 고객 언어(실제 고객이 쓰는 표현), 브랜드 톤
- 성과 지표, 고객 후기, 근거 자료
