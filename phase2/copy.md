# 택스봇 랜딩페이지 카피 (시안 1 기준)

**기준 문서:** phase1/final.md
**선택 시안:** 시안 1 (비용·수고 사이의 빈자리)
**페이지 목적:** 1인 프리랜서가 카드를 연결하고 신고용 엑셀을 만들어 보게 하는 것
**섹션 구성:** Hero, Problem, Solution, CTA (4개)
**작성일:** 2026-11-13

---

## 1. Hero

**헤드라인**
세무사 쓰기엔 아깝고, 직접 하긴 귀찮은 부가세

**서브헤드**
카드 내역을 연동하면 부가세 신고용 엑셀을 클릭 한 번으로 받습니다.

**CTA 버튼**
내 카드 내역으로 엑셀 만들기

**버튼 아래 문구**
[NEED: 가격 또는 무료 여부, 카드 정보 보호 안내]

---

## 2. Problem

**섹션 제목**
부가세 신고 때마다 같은 선택을 합니다

**본문**
세무사에게 맡기자니 1인 프리랜서에게는 비용이 부담스럽습니다.
직접 하자니 신고 기간마다 카드 내역을 하나씩 열어 정리해야 합니다.
돈을 쓰거나, 시간을 쓰거나. 어느 쪽도 내키지 않는 선택입니다.

**근거 자리**
[NEED: 세무사 대행 평균 비용, 수작업 정리에 걸리는 시간. 확인된 수치가 있을 때만 넣는다]

---

## 3. Solution

**섹션 제목**
카드를 연결하고, 클릭 한 번이면 됩니다

**3단계**

1. **카드 내역 연동**
   사용하는 카드를 택스봇에 연결하면 사용 내역을 가져옵니다.
   [NEED: 지원 카드사 목록]

2. **클릭 한 번**
   엑셀 만들기 버튼을 누릅니다.

3. **신고용 엑셀 받기**
   부가세 신고용 엑셀 파일이 만들어집니다. 신고 자료로 사용하세요.

**마무리 문장**
세무사에게 맡기지 않고도 부가세 신고 자료를 준비할 수 있습니다.

---

## 4. CTA

**섹션 제목**
이번 신고 기간의 카드 내역 정리는 택스봇에 맡기세요

**서브헤드**
카드를 연결하고 클릭 한 번이면 부가세 신고용 엑셀이 나옵니다.

**CTA 버튼**
내 카드 내역으로 엑셀 만들기

**버튼 아래 문구**
[NEED: 가격 또는 무료 여부, 카드 정보 보호 안내]

## 작성 메모

**적용한 원칙**
- 헤드라인은 소개 문구의 고객 언어("아깝다", "귀찮다")를 그대로 썼다.
- Solution은 원문에 있는 기능 두 가지(카드 내역 연동, 원클릭 엑셀)만 설명한다.
- 서브헤드는 결과물(신고용 엑셀)과 행동(클릭 한 번)을 한 문장에 넣었다.
- CTA 버튼은 "시작하기" 대신 얻는 결과를 적었다.

**쓰지 않은 표현과 해제 조건**
| 표현 | 이유 | 해제에 필요한 근거 |
|---|---|---|
| 자동 신고, 홈택스 제출 | 원문에 신고 제출 기능이 없다 | 홈택스 연계 기능 명세 |
| 정확한 계산, 오류 없음 | 정확도 검증 자료가 없다 | 계산 로직 검수 기록 |
| 절세, 환급 | 효과를 뒷받침할 자료가 없다 | 사례 데이터와 세무 검토 |
| 저렴한, 무료 | 가격 미확인 | 가격표 |
| 안전한, 보안 | 보안 정책 미확인 | 개인정보·보안 정책 문서 |

**확정 전 확인할 항목**
1. 가격과 무료 여부 (두 CTA 아래 문구)
2. 카드 정보 보호 방식 (연동에 대한 가장 큰 망설임)
3. 지원 카드사
4. 엑셀이 신고에 어떻게 쓰이는지, 사용자가 홈택스에 직접 입력하는지
5. Problem 섹션에 넣을 비용·시간 수치
